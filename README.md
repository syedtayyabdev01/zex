# ZEX Android V0.3

ZEX is a lightweight Android WebView app for `https://zxcstream.com/`, with a red ZEX identity and a translucent glass control bar. The app respects the site's own sign-in, playback, DRM, provider, and access rules.

## Android and Android TV

- One APK supports phones, tablets, and Android TV. TV launch and touchscreen-optional support are declared in the manifest.
- Use a TV remote's directional pad to focus the glass controls and the site's own controls. Play/pause media keys are passed to the page's active video element.
- The compact glass controls auto-hide during page use and movie playback so they don't cover titles or player controls. Tap the very top edge on a phone, or press Menu on a TV remote, to reveal them briefly.
- The WebView uses the site's responsive viewport without overview zoom, so its layout can use the available phone or TV width. The compact ZEX wordmark stays on one line on phones.
- The site-only PWA `Install` item is hidden inside the Android WebView, where browser install prompts aren't supported. The website's normal install option remains available in a supported browser.
- Web video fullscreen is supported. HTTPS-only navigation stays within `zxcstream.com`; other HTTPS links are handed to the system browser.
- If the website reports that playback is unavailable inside WebView, ZEX shows an **Open this page in Chrome** fallback. This helps when the same page plays in Chrome; the site's player/source still determines whether the title is actually available.
- In the site's "Stay Connected" popup, ZEX links to its Discord server, Telegram channel, and GitHub repository.
- A low-power daily reminder and GitHub release check run on a 24-hour WorkManager interval. A newer release gets one update alert; installing an app update also shows a confirmation notification. Android may defer daily background work, and notifications require the user's notification permission.

## Build

Requirements: JDK 17, Android SDK Platform 35, and Android Build Tools 35.x.

```powershell
.\gradlew.bat assembleDebug
.\gradlew.bat assembleRelease
```

The debug APK is `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions builds the APK on pushes and publishes a downloadable APK when the `v0.3` tag is pushed. Unsigned release APKs are for sideloading/testing; sign with your own private keystore before distribution.

## Install on Android TV

Download the debug APK from the GitHub Actions run (or the release APK), then install it using Android Studio/ADB or a trusted sideloading method. In the app, use the TV remote D-pad for navigation. Playback and provider support depend on the website and its embedded players.

## Security and privacy

- Only HTTPS is permitted; cleartext traffic and mixed content are disabled.
- JavaScript and DOM storage are enabled for the website. Cookies are retained by WebView for site sessions.
- File/content access and app backups are disabled. No credentials or signing keys belong in this repository.
- Glass panels use a translucent gradient and thin highlight border without live blur or continuous animation, keeping rendering lightweight.

## Video quality

ZEX displays the quality options supplied by the website's player/source. The app cannot create a 1080p stream or force a provider to offer one. When 1080p is available, choose it in the player's quality menu; actual quality also depends on the source and connection.

## ZEX for Windows PC

The Windows desktop app opens the responsive ZEX website in a resizable, keyboard-friendly window. It has a lightweight glass toolbar, browser back/home/reload controls, and fullscreen video support. Website playback and account features follow the website's own support.

- Download `ZEX-PC-v0.1.0-win-x64.zip` from the [PC V0.1.0 release](https://github.com/syedtayyabdev01/zex/releases/tag/pc-v0.1.0), extract it, and run `ZEX.exe`.
- Windows 10/11 x64 is targeted. Microsoft Edge WebView2 Runtime is required; it is commonly present with Edge, and the app offers Microsoft's installer page if missing.
- Keyboard: `Alt+Left` back, `Alt+Right` forward, `Ctrl+H` home, `Ctrl+R` reload, `Esc` exit video fullscreen.
- To build locally, install the .NET 10 SDK and run `dotnet publish desktop/Zex.Desktop.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o desktop/publish`.

The Windows build is generated by GitHub Actions and attached to the `pc-v0.1.0` release. The app uses Microsoft's WebView2 component to display the same responsive website, so it stays small and does not bundle a second copy of the site's content.

## iPhone test build

The SwiftUI/WebKit test build targets iOS 14 and newer and is packaged as an unsigned arm64 IPA for TrollStore testing. TrollStore itself only works on supported firmware versions. On other iOS versions, use a signing/sideloading method supported by that device.
