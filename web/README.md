# ZEX Web

Static landing and downloads page for the ZEX cross-platform clients.

## Deploy on Vercel

The Vercel project root is configured to this directory. This is a static HTML page and requires no package installation or build step.

## Scope

This page links to the existing GitHub release pages for Android, Windows, and iOS test builds. The native apps and their existing build workflows are kept separate. The connected streaming website, catalogue, accounts, and playback providers are not hosted in this repository.
